parameterised test case (data-driven testing, M-9).

  - "schema": { "fields": [ { "name": string, "type": string, "required": bool } ] }

  - `expected` is a JSON object describing the expected outcome
    (e.g. {"status": "accepted"} or {"status": "rejected", "error": "..."}).
  - Do NOT add fields outside the schema.
  - Keep values short and machine-parseable.

Reply with STRICT JSON (no markdown fences, no prose), exactly:
{
  "rows": [
    {
      "values": { ... },
      "expected": { ... },
      "category": "typical" | "boundary" | "invalid"
    }
  ]
}
