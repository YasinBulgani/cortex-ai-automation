INSTALLATION & USAGE
================================================================================

1. SETUP BACKEND (15 minutes)
   $ cd backend
   $ alembic upgrade head
   $ python scripts/seed_test_users.py
   $ uvicorn app.main:app --port 8000

2. RUN TESTS (2 minutes)
   $ mvn test -Dtest=karate.TestRunner -Dkarate.threads=5

3. VIEW RESULTS (1 minute)
   $ open target/karate-reports/karate-summary.html

QUICK COMMANDS:
   Smoke tests:   mvn test -Dtest=karate.TestRunner --tags @smoke
   Critical:      mvn test -Dtest=karate.TestRunner --tags @critical
   RBAC:          mvn test -Dtest=karate.TestRunner --tags @rbac
   All tests:     mvn test -Dtest=karate.TestRunner
